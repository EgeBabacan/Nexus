## 🚀 NEXUS Template Overview

NEXUS is a premium, fully responsive Business & Corporate HTML template designed for modern agencies, consulting firms, startups, and corporate businesses. Built with clean code, semantic HTML5, CSS3 animations, and zero framework dependencies for maximum performance and customization flexibility.

### ✨ Key Features

- **Fully Responsive Design** - Perfect on all devices from mobile to desktop
- **15+ Pre-built Pages** - Homepage, about, services, portfolio, blog, and more
- **Modern CSS Grid & Flexbox** - Future-proof layout system
- **Zero Dependencies** - No jQuery or heavy frameworks required
- **SEO Optimized** - Schema markup, semantic HTML, optimized meta tags
- **Performance First** - 95+ Google PageSpeed score
- **Accessibility Compliant** - WCAG 2.1 AA standards
- **Dark/Light Theme Ready** - CSS custom properties for easy theming
- **Cross-Browser Compatible** - Works in all modern browsers

## 🛠️ Quick Start Guide

### 1. Download & Extract
Extract the ZIP file to your web server or local development environment.

### 2. Open in Browser
Simply open `index.html` in your browser or upload to your web server.

### 3. Customize
- **Colors**: Edit CSS custom properties in `assets/css/variables.css`
- **Content**: Update text content directly in HTML files
- **Images**: Replace placeholder images in `assets/images/`
- **Styling**: Modify component styles in respective CSS files

### 4. Deploy
Upload all files to your web hosting server and update paths if needed.

## 🎨 Customization Guide

### Color Scheme
All colors are defined using CSS custom properties in `variables.css`:

```css
:root {
  --color-primary: #2563eb;     /* Primary brand color */
  --color-accent: #f59e0b;      /* Accent/CTA color */
  --color-text: #1f2937;        /* Main text color */
  --color-bg: #ffffff;          /* Background color */
  /* ... more color variables */
}
```

### Typography
The template uses Google Fonts (Sora + DM Sans). To change fonts, update the Google Fonts link in HTML head and CSS font-family properties.

### Layout & Spacing
Consistent spacing is achieved through CSS custom properties:
```css
--space-xs: 0.25rem;   /* 4px */
--space-sm: 0.5rem;    /* 8px */
--space-md: 1rem;      /* 16px */
--space-lg: 1.5rem;    /* 24px */
/* ... more spacing variables */
```
